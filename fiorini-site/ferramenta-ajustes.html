Ajustes Fiorini

Esta página aplica as 5 trocas combinadas no arquivo que está publicado hoje, sem mexer em mais nada: pixels, códigos e imagens continuam iguais. Os arquivos ficam no seu computador; nada é enviado para lugar nenhum. Se algum trecho não estiver exatamente igual, ela não gera o arquivo e mostra o que achou, para você me mandar.

A

Baixar os arquivos que estão no ar

  1. No hPanel: Sites → site da Fiorini → Gerenciador de Arquivos → abra a pasta public_html.Se pedir login ou código 2FA, faça e volte para cá.
  2. Clique com o botão direito em index.html → Download. Esse é o arquivo da página principal.
  3. Abra a pasta implantes → botão direito em index.html → Download.O Chrome vai salvar como index (1).html; tudo bem. Se não existir a pasta implantes, procure implantes.html direto no public_html e baixe esse.
B

Ajustar aqui

  1. Arraste cada arquivo para o quadro certo abaixo (ou clique no quadro e escolha). Todas as linhas precisam ficar verdes.
  2. Clique em Baixar arquivo ajustado nos dois quadros. Vão para Downloads com os nomes index-AJUSTADO-principal.html e index-AJUSTADO-implantes.html.Se algum quadro ficar vermelho, pare aqui: clique em Copiar relatório e cole para mim na conversa.
C

Fazer o backup e subir na Hostinger

O backup é o próprio arquivo original, renomeado na mesma pasta. Faça os passos 7 e 8 um logo depois do outro: entre eles a página fica alguns segundos fora do ar.

  1. No public_html: botão Upload (seta para cima, no topo) → escolha index-AJUSTADO-principal.html. Espere ele aparecer na lista.
  2. Backup: botão direito em index.html → Rename (Renomear) → index.backup-2026-11.html
  3. Botão direito em index-AJUSTADO-principal.html → Rename → index.html
  4. Entre na pasta implantes e repita os passos 6 a 8 com index-AJUSTADO-implantes.html: backup index.backup-2026-11.html e o ajustado renomeado para index.html.Se a página for implantes.html na raiz: backup implantes.backup-2026-11.html e o ajustado renomeado para implantes.html.
D

Conferir no site publicado

  1. Abra o site com ?v=2611 no fim do endereço (ex.: seusite.com.br/?v=2611) e aperte Ctrl+Shift+R. O menu mostra Alinhador; embaixo de Dra. Claudia Fiorini aparece CRO-SP 589011; embaixo de Dr. James Fiorini aparece CRO-SP 76945.
  2. Aperte Ctrl+U (código da página) → Ctrl+F → digite 100 mil. Tem que dar 0 resultados.Conferir no código pega também o texto que não aparece na tela, como a descrição para o Google.
  3. Faça o mesmo em seusite.com.br/implantes/?v=2611: Ctrl+U → Ctrl+F 100 mil → 0 resultados. A frase “Implante · Protocolo · Reabilitação · Vargem Grande do Sul-SP” continua lá.
  4. Se ainda aparecer a versão antiga: no hPanel, abra a área de Cache ou CDN do site, clique para limpar o cache e confira de novo.

Se algo der errado no site

Na pasta da página com problema: renomeie index.html para index-com-erro.html e depois index.backup-2026-11.html para index.html. A página volta a ser exatamente a de antes.
